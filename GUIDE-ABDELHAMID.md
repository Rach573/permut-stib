# Permut’ STIB — guide de démonstration pour Abdelhamid

Bonjour Abdelhamid,

Permut’ STIB est une application de démonstration destinée à faciliter l’entraide entre agents pour les permutations de vacances et les signatures de service.

## Accès

- Application en ligne : https://permut-stib-alpha.onrender.com/
- Application Android : installer `Permut-STIB-Alpha-v8.apk` sur un smartphone Android 8 ou plus récent.
- Compte délégué : `DELEGUE`
- Mot de passe du délégué : `test1234`

Comptes agents conseillés pour les essais :

| Profil | Identifiant | Mot de passe |
|---|---|---|
| Agent de test 1 | `70-001` | `test1234` |
| Agent de test 2 | `70-005` | `test1234` |
| Agent de test 3 | `70-007` | `test1234` |

Les agents actifs `70-001` à `70-042` utilisent tous le mot de passe `test1234`. Les comptes `70-043` à `70-046` sont volontairement en attente, `70-047` et `70-048` sont suspendus, et `70-049` et `70-050` sont refusés afin de tester la gestion administrative.

## Fonctions principales

### Côté agent

- publier une demande de permutation de vacances ;
- rechercher une permutation et proposer un échange ;
- suivre ses demandes et confirmer un accord ;
- demander la signature d’un collègue pour une date ;
- proposer des dates auxquelles on est disponible pour signer ;
- consulter « Mes signatures » et répondre aux demandes ;
- recevoir des notifications lorsqu’une demande correspond à une recherche, lorsqu’un collègue propose une signature ou lorsqu’un accord évolue.

Le numéro de téléphone d’un agent n’est jamais affiché aux autres agents.

### Côté délégué

- consulter la vue administrative ;
- activer, suspendre ou refuser un compte agent ;
- suivre les permutations et les signatures ;
- consulter les informations nécessaires au contrôle et au suivi ;
- accéder aux numéros de téléphone, réservés au compte délégué.

## Parcours de démonstration conseillé

1. Se connecter avec `DELEGUE` pour présenter la vue administrative et l’état des comptes.
2. Se connecter avec `70-001` pour montrer les rubriques « Permutations » et « Signatures ».
3. Utiliser un deuxième agent, par exemple `70-005`, pour répondre à une demande et observer les notifications.
4. Créer un nouvel agent, puis revenir sur le compte `DELEGUE` pour l’activer.

## À savoir

- Cette version est une version alpha de démonstration : les comptes et données sont fictifs.
- Une connexion Internet est nécessaire pour utiliser l’APK.
- Lors de l’installation, Android peut demander d’autoriser temporairement les applications provenant de cette source, car cette version de test n’est pas distribuée par le Play Store.
- L’hébergement gratuit peut mettre environ une minute à se réveiller lors de la première ouverture après une période d’inactivité.
- Le mot de passe simple `test1234` est réservé à cette démonstration et devra être remplacé avant une utilisation réelle.
